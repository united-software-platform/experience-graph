# experience-graph

**experience-graph** — система управления профессиональным опытом, которая агрегирует опыт из разных
источников, связывает его с подтверждающими кейсами и формирует адаптированные представления опыта
под конкретные задачи.

## Основная идея

Профессиональный опыт хранится как **граф знаний**, а резюме и другие документы являются его представлениями.

```text
Experience
    ↓
Cases & Evidence
    ↓
Skills / Projects / Technologies / Results
    ↓
Context
    ↓
Resume / Profile / Portfolio
```

---

## Возможности

- агрегация профессионального опыта;
- структурирование опыта в граф;
- связь опыта с конкретными кейсами и доказательствами;
- извлечение навыков, технологий, ролей и результатов;
- поиск релевантного опыта под конкретную вакансию;
- адаптация резюме под целевой контекст;
- сохранение единого источника истины для профессионального профиля.

---

## Принцип

> **Resume is a view of the Experience Graph, not the source of truth.**

Проект ориентирован на создание **evidence-based professional profile**, где утверждения об опыте
подкреплены конкретными кейсами и результатами.
